# Описание задачи  
Разработать функцию is_palindrome(text), которая проверяет, является ли переданная строка палиндромом. Палиндром — строка, которая читается одинаково слева направо и справа налево. При проверке необходимо игнорировать регистр, пробелы и знаки препинания.
# Требования к тестам  
- Наличие тестов для явных палиндромов (например, "А роза упала на лапу Азора").  
- Наличие тестов для не-палиндромов.  
- Наличие тестов, проверяющих игнорирование пробелов и знаков препинания.  
- Наличие тестов для пустой строки и строки из одного символа.
